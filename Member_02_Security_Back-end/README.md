# Member 02: Backend Security
## (Member_02_Security_Back-end)

### Main Tasks:
- **Spring Security Configuration:** Setting up `WebSecurityConfigurerAdapter` (or `SecurityFilterChain`).
- **Authentication & Authorization:** Implementing user authentication logic.
- **Role-based Access Control:** Defining roles like `USER` and `ADMIN`.
- **Password Encoding:** Using BCrypt for secure password storage.

### Current focus:
Ensuring the application is secure and that user sessions are handled correctly using Spring Security.
