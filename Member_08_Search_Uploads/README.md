# Member 08: Search & Uploads
## (Member_08_Search_Uploads)

### Main Tasks:
- **Implementing "Beyond CRUD" Feature:**
    - **Advanced Search/Filtering:** Filtering products by name, category, or price range.
    - **File Uploads:** Implementing a system to upload and store product images with server-side validation.
    - **File Handling:** Ensuring images are correctly saved in `product-images` and served to the UI.

### Technical Requirements:
- **Validation:** Server-side validation for all file uploads.
- **Backend:** Layered architecture (Service -> Repository).
- **Frontend:** Use form binding and proper validation error display.

### Current focus:
Adding advanced functionality that goes beyond basic data management.
