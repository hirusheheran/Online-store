# Member 01: Setup & Infrastructure
## (Member_01_Setup_Infra)

### Main Tasks:
- **Project creation:** Ensure the project structure is clean and correctly initialized.
- **README setup:** Create a comprehensive project README that includes:
    - Project description
    - Technologies used (Spring Boot, Thymeleaf, MySQL, CSS)
    - Installation and setup instructions
    - Database configuration details
    - Contributor roles and responsibilities

### Technical Requirements (Global Standards):
- **Arch:** Layered (Controller -> Service -> Repository -> Entity).
- **Security:** Spring Security for Auth & Auth.
- **Non-Functional:** Performance, Security, Reliability (404/401/403), Code Quality.
- **Feedback:** Use @ControllerAdvice for global error handling.

### Current focus:
Overseeing the repository organization and ensuring all dependencies in `pom.xml` are correctly configured for the team.
